# Простой калькулятор

Небольшой калькулятор на чистом HTML, CSS и JavaScript. Все файлы собраны в одном документе.

## Запуск

Откройте `index.html` в любом современном браузере.

Поддерживаются сложение, вычитание, умножение, деление, проценты и смена знака. Можно использовать кнопки или клавиатуру: цифры, `+`, `-`, `*`, `/`, `.`, `Enter` и `Esc`.
